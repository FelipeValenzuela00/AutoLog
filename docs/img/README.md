# Capturas

GIFs que usa el README principal. Grabados con Playwright con una empleada ficticia y datos de ejemplo.
1280×720 escalado a 960 px, 12 fps.

| Archivo | Qué muestra |
|---|---|
| `dashboard.gif` | Actividad del día (Calendar, Drive, Jira), métricas y distribución por fuente |
| `generar-informe.gif` | Generación del informe diario con IA |
| `actividad-manual.gif` | Alta de una actividad manual y recálculo de métricas |
| `historial.gif` | Historial de informes enviados |
| `configuracion.gif` | Configuración del horario de la jornada |

Para regrabarlos: proyecto `portfolio-grabaciones` (`node autolog/grabar.js`).
